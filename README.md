# Chess Position Monitor

A Node. - python application that interfaces with the Lichess API to monitor chess game state changes. **This is an educational project to demonstrate API integration and event-based programming.**

## Purpose

This project was created as a learning exercise to demonstrate:
- RESTful API design principles
- Third-party API integration (Lichess)
- Asynchronous JavaScript programming
- State management in server applications
- Event-driven architecture

## Technical Details

- **Backend**: Express.js server with RESTful endpoints
- **API Integration**: Fetches game data from Lichess API
- **Authentication**: Supports OAuth and public endpoint access
- **State Management**: Tracks game state transitions
- **Event Detection**: Monitors turn changes and board positions

## Educational Use Only

This project is intended for educational purposes to demonstrate programming skills. Using automated tools during chess games violates the terms of service of chess platforms and fair play principles.

## Legitimate Use Cases

- Learning RESTful API design
- Understanding asynchronous JavaScript patterns
- Practicing state management in applications
- Post-game analysis (not during active games)
- Educational demonstrations of API integration
